# AI 다인 맵 성능 베이스라인 (100시드)

다인(3인+) 맵 AI의 성능 기준 데이터. **AI 로직을 바꿀 때마다 이 표와 비교**해 회귀/개선을 판정한다.
모든 수치는 **100시드** 동기식 전체게임 시뮬레이션 평균(셋업만 시드 고정, AI 결정은 실난수 — 8/20시드는
편차가 커 노이즈가 크므로 반드시 100시드 이상으로 측정).

## 측정 방법

```bash
npx vitest run src/ai/__tests__/rustBeltSimulation.test.ts \
  src/ai/__tests__/koreaSimulation.test.ts \
  src/ai/__tests__/germanySimulation.test.ts \
  src/ai/__tests__/westernUsSimulation.test.ts 2>&1 | \
  grep -aE "=====|평균 accurate|파산: |1번\(선공\)|최종 승자|player[1-6]: VP"
```

출력 지표: 평균 accurateVP(완성 링크 트랙만 +1), 파산/게임, 1번(선공) 점유 분포, **최종 승자 분포**,
**player별 평균**(건설/수송/엔진/주식/income/VP/완성트랙). player별 지표는 player-index 편향 진단용.

- 2인 맵(tutorial·St.Lucia)은 순서 고착 개념이 약해 이 표에서 제외. tutorial VP 회귀는 고정시드
  `fullGameSimulation.test.ts`가 별도 게이트(평균 ≥ 9.3, 파산 0). ⚠️ St.Lucia(2인)는 현재 기존부터
  AI 파탄 상태(VP ≈ −23, 파산 18/20) — 경매 변경과 무관한 별도 미해결 이슈.

## 이번 작업 요약 (경매 순서 고착 → 골고루)

- **달성**: 원래 문제("한번 꼴찌면 항상 꼴찌" = player-index 단조 편향)는 해소. Korea VP 17→20,
  Germany 거의 균등(승자 25/12/25/38).
- **turnOrder 가중치 = 양날의 검(전 구간 100시드 스윕)**: "골고루"를 위해 turnOrder 행동에 rank 비례
  가중치를 줬으나, 이게 오히려 **뒤 순서 플레이어에게 1번을 독식시켜 단조 편향을 만들고 VP를 깎는
  주범**이었다. 0.1(거의 끔)이 최적 — 0.1~0.2 무효(평범한 행동 0.3에 밀림), 0.3~0.4 작동하나
  VP 악화+독식 재현(Korea 20.2→10.5/9.4), 1.8 심한 독식. **약한 특수행동에 인위적 가중치는 부작용만.**
- **Korea 거점 보정**: 동적색 맵(`board.dynamicCityColors`)에서 AREA_BIAS off + 경로금지(-Infinity→감점)
  완화. player2(부산 고립 거점) 독점은 거점/순서 구조 문제라 완전 해소는 안 됨.

## 잔존 과제 (turnOrder 무관, 구조적)

1. **Western 6인 "앞 순서 유리"** (앞3 ~30 vs 뒤3 ~−5): 인원 많을수록 선공이 공짜 이득. 올바른 해법은
   인위적 보정이 아니라 **선공의 구조적 가치를 경매 입찰에 반영**해 앞 순서를 비싸게 사게(돈→VP 상쇄) 하는 것.
2. **Korea P2 독주**: 부산 고립 거점 + 동적색.
3. **St. Lucia(2인) 기존 파탄**: VP −23, 파산 18/20 (별개 이슈).
