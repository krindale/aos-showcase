# AI 다인 맵 성능 베이스라인 (100시드)

다인(3인+) 맵 AI의 성능 기준 데이터. **AI 로직을 바꿀 때마다 이 표와 비교**해 회귀/개선을 판정한다.
모든 수치는 **100시드** 동기식 전체게임 시뮬레이션 평균(셋업만 시드 고정, AI 결정은 실난수 — 8/20시드는
편차가 커 노이즈가 크므로 반드시 100시드 이상으로 측정).

## 측정 방법

```bash
npx vitest run src/ai/__tests__/rustBeltSimulation.test.ts \
  src/ai/__tests__/koreaSimulation.test.ts \
  src/ai/__tests__/germanySimulation.test.ts \
  src/ai/__tests__/westernUsSimulation.test.ts \
  src/ai/__tests__/southernUsSimulation.test.ts \
  src/ai/__tests__/moonSimulation.test.ts -t "베이스라인" 2>&1 | \
  grep -aE "=====|평균 accurate|파산: |1번\(선공\)|최종 승자|경매 입찰|1번 획득|turnOrder 행동|player[1-6]: VP"
```

출력 지표: 평균 accurateVP(완성 링크 트랙만 +1), 파산/게임, 1번(선공) 점유 분포, **최종 승자 분포**,
**player별 평균**(건설/수송/엔진/주식/income/VP/완성트랙). player별 지표는 player-index 편향 진단용.

- 2인 맵(tutorial·St.Lucia)은 순서 고착 개념이 약해 이 표에서 제외. tutorial VP 회귀는 고정시드
  `fullGameSimulation.test.ts`가 별도 게이트(평균 ≥ 9.3, 파산 0). ⚠️ St.Lucia(2인)는 현재 기존부터
  AI 파탄 상태(VP ≈ −23, 파산 18/20) — 별도 미해결 이슈.

## 진단 지표 (상시 출력, player-index 편향·순서 고착 추적용)

각 다인 시뮬 로그에 아래 진단 지표가 **항상** 출력된다(2026-06-25 추가). "누가 1번을 먹나·왜 정체하나"를
수치로 추적해 인위적 보정 없이 진짜 원인을 규명하는 도구다.

- **경매 입찰 발생**: N회/게임. 0에 가까우면 경매가 양보로만 결정 = 순서 안 섞임.
- **1번 획득 — 입찰로(byBid) / 양보로(byYield)**: 1번을 돈 주고 따냈나(byBid) vs 아무도 안 사서 됐나(byYield).
- **turnOrder 행동 선택 횟수**: player별 turnOrder 선택 — 순서 탈환 시도 빈도.
- **순번 1~N위 점유 분포**(Western): player별 각 순번 횟수. "앞 절반 고착" 직접 진단.
- **(Western) 1게임 턴별 프로세스 추적**(`-t "프로세스 추적"`): player별 매 턴 경로/건설좌표 + skip 시
  게이트 이유(완성/from·to연결/completable/필요트랙). 정체·붕괴 원인 추적의 핵심.

## 현재 베이스라인 (2026-07-21b, 달 재무 튜닝 — 후반 계획 발행 금지)

달 봇 진단(턴별 계측)에서 **매 턴 적자**가 드러났다: income은 턴당 +2 오르는데 비용(주식+엔진)은
+2.3 올라 T8에 수지 −8.3. 봇이 1~6턴 내내 발행 캡(2주)을 채워 주식 14.7 = **VP −44**가
income 16.8을 압도. 근본 산술 — 달은 크레이터 \$3·건설 2개 제한이라 주식 1주(\$5)로 1.67타일뿐이고
링크 완성엔 2~3타일이 필요해 **3턴 이후 차입은 회수 불가**(−3VP + 유지비 vs +1.5VP).

채택 3종 (전부 달 전용 MapProfile 훅, 다른 맵 기본값은 기존 동작과 항등):

2. **운영비 income 상계**(`aiPlanExpensesNetOfIncome`) — cashNeeded의 발행 자기증폭 고리 차단
3. **배달 타이밍 계수**(`aiDeliveryTimingFactor`) — 검은 큐브 우대(매 턴 배달처 존재), 목적지가

   곱하면 `expectedDeliveries = min(deliverableTurns, matchingCubes)`의 큐브 병목에 묻혀 무효(실측 0.03)
4. **반구 포트폴리오 다양화**(같은 훅 안, `coveredSides`) — 내 완성 링크가 이미 커버한 반구는

### 수송 스킵 구조 (2026-07-21b 4분류 실측, 12시드)
수송 기회의 38~40%가 스킵인데, 사유를 나누면 **대부분이 룰의 본질**이라 추가 개선 여지가 작다:
| 사유 | 비중 | 성격 |
|---|---|---|
| ① 배달할 큐브 없음 | 0% | 공급은 충분 (봇 Production 구현 이후) |
| ② 밤낮 차단 | 41% | 목적지가 격턴에만 열림 — 반구 포트폴리오로 일부만 완화 가능 |
| ③ 도달 불가 | 34% | 네트워크 부족 (건설 2개 제한의 구조적 결과) |
| ④ 자발적 스킵 | 25% | **포기한 배달의 평균 내 링크 0.08 = income 0** → 봇 판단이 옳음 |
④가 income 0짜리라 `moveGoods`의 `bestMoveVP > 0` 문턱을 완화해도 얻을 게 없다(기대 income
+0.5/게임, 4인 합계). 즉 "스킵을 줄이는" 방향의 남은 레버는 ②·③뿐이고 둘 다 건설 속도에 묶여 있다.

### 엔진 상한 실험 (2026-07-21c) — engineMax와 "엔진업 결정 상한"의 분리
`engineMax`를 낮추면 `vp.ts:367`이 그보다 긴 경로를 −∞로 배제해 income 천장까지 내려간다(앞선
기각). 그래서 **경로 평가는 engineMax 그대로 두고 엔진업 결정만 제한**하는 `aiEngineUpgradeCap`을
신설했다(기본 null = engineMax = 기존 동작).
- **채택**: 달 `aiEngineUpgradeCap=3` (수송 라운드 엔진업만 제한) → VP −12.98→**−12.73**
- **기각**: 같은 상한을 `selectAction`의 Locomotive front-load에도 적용 → 엔진이 3.0으로 고정되며
  VP −13.55·income 6.55→6.2 악화(4링크 배달이 막힘). 단 **player 편차는 크게 축소**
  (player3 −21.4→−15.3, 최대-최소 17.4→9.4) — 순번 편향 해소 축에서 재검토할 가치가 있다.

## 직전 비교 기준 (2026-07-14b, 타이밍 실비 모델 + 페널티 8→4)

페널티 8에서도 2턴 완성 장거리(côteVertu→atwater, 6타일 $15 3링크, VP 29.5)가 1턴 완성
단거리(berriUqam→atwater, 3타일 $8 2링크, 27.5)를 이김 — 사용자가 이 행동을 원치 않았고,
원인 진단은 "엔진업 가정(engineDelay, 턴당 1업글)은 있는데 그 **비용**이 점수에 없다"였다.
`min(배달가능턴, 매칭큐브)`에서 큐브(2개)가 병목이라 지연이 배달 횟수에 반영 안 되고, 현금
흐름은 "지금부터 남은 턴 전체"로 낙관 계산되던 것. 페널티 상향(Montréal 11 오버라이드,
−3.37/1.21)은 순위를 뒤집지만 강제 비용이 커서 **기각**하고, 실비 직접 계산으로 교체:

1. **배달 시작 지연 현금 흐름 차감** — `deliveryDeltaVP`에 `startDelay = max(완성턴−1, 엔진지연)`
   파라미터: 그 턴 수만큼 현금 흐름을 못 번다 (즉시 배달 평가는 delay 0).
2. **엔진 증분 유지비 청구** — 경로가 요구하는 엔진 +d레벨은 매턴 $1 지출:
   `Σ_{k=1..d}(남은턴−k+1) × λ`를 경로 비용에 합산 (`engineUpkeepVP`).
3. **지연 완성 페널티 8→4** (`MapProfile.lateCompletionPenaltyPerTurn` 기본값) — 페널티는
   실비의 프록시였으므로 실비가 계산되면 절반으로 축소해야 이중 청구가 안 됨
   (8 유지 시 Southern −1.06 게이트 초과 회귀 실측). Montréal 오버라이드는 제거 —
   기본값으로도 즉시 경로 자연 우선 (berri 21.0 > côteVertu 15.0, 페널티 4에선 19.0).
