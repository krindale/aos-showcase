## 3. 🔴 Korea 회귀 — `blockedEdges`를 AI 경로탐색이 모름

이번 브랜치는 한국 산맥을 **건설 불가 경계 변(`board.blockedEdges`)** 으로 추가했다. 게임 엔진의 건설 가드(`canBuildTrack`)에는 반영됐으나 **AI 경로탐색(A* `analyzer.ts`, `buildTrack.ts`의 `tryDirectPathBuild`)에는 반영되지 않았다.** AI는 산맥을 가로지르는 경로를 계획한 뒤 건설 단계에서 막혀 슬롯을 낭비한다.

### 동일 8시드 직접 비교 (도입 직전 `fccc97a` vs 현재 `main`)

| 지표 | 도입 전 | 도입 후 | 변화 |
|---|---:|---:|---:|
| **평균 VP** | **23.38** | **13.72** | **−9.66 (−41%)** |
| income | 13.75 | 11.59 | −2.16 |
| 완성트랙 | 8.11 | 6.22 | −1.89 |
| 발행주식 | 8.66 | 9.09 | +0.43 |
| 건설 | 44.3 | 37.0 | −7.3 |
| 배달 | 40.8 | 31.8 | −9.0 |
| 파산 | 0.88명 | 1.63명 | +0.75 |

### VP −9.66의 분해
```
income  기여: (11.59 − 13.75) × 3 = −6.5 VP
완성트랙 기여: (6.22 − 8.11) × 1  = −1.9 VP
발행주식 기여: −(9.09 − 8.66) × 3 = −1.3 VP
합계 ≈ −9.7 VP  ✓
```

### 로그 증거 (1게임 추적)
- 건설 성공 46회 vs **스킵 23회 + 회피 재탐색 28회** — 건설 시도의 절반 가까이가 막혀 재시도/포기.
- 회피 재탐색 최다 좌표 **(3,3) 8회** = blockedEdges `(3,3)-(4,3)` 산맥 경계의 한쪽. AI가 산맥을 모르고 그 변을 건너는 경로를 짜 8번 반복 실패. 인접 (3,4)·(2,3)도 추가.

### 원인 사슬
```
blockedEdges 추가
  → AI A*/tryDirectPathBuild가 막힌 변을 회피 안 함
  → 산맥 가로지르는 경로 커밋 → canBuildTrack에서 거부
  → 건설 슬롯 낭비(스킵·재탐색) → 건설↓ 배달↓ 완성트랙↓
  → income↓ + 자금난으로 발행↑·파산↑
  → VP 23.4 → 13.7 (−41%)
```

## 4. 전 맵 공통 — 점수를 누르는 두 구조적 요인

income 자체는 맵별 8~11로 나쁘지 않다. VP를 깎는 것은 다음 두 가지다.

1. **발행주식 부채**: 7~12주 × −3VP = **−21~−36VP**. 후반 현금이 과잉으로 쌓이는 것(2절)에서 보이듯, 회수 못 할 발행이 −VP로만 남는다.
2. **미완성 트랙**: 건설 타일의 약 40%가 완성 링크에 들지 못해 **VP 0 + income 0**(자금만 소모). Korea 기준 건설 9타일/인 중 완성 5.5타일.

## 5. ⚪ St. Lucia 파산 70% (회귀 아님)

발행주식 **12.4주**(−37VP) + 배달 0 → 수입 0 → 매 턴 비용만 누적 → 파산 70%. St. Lucia AI income 전략은 원래 미완성 영역(목표 게이트 `it.skip`, "재설계 예정"으로 문서화)이라 이번 브랜치와 무관하다.

## 6. 권장 수정 (효과 큰 순)

1. **AI 경로탐색에 `blockedEdges` 반영** — `getNeighborHex` 확장 지점(analyzer A* `findPath`, `buildTrack`의 `tryDirectPathBuild`)에서 `isBlockedEdgePair`로 막힌 변을 이웃에서 제외. **Korea VP를 ~23으로 회복**시킬 핵심 수정. 게임 엔진엔 이미 가드가 있으므로 AI만 가르치면 된다.
2. **issueShares ΔVP 보수화** — 회수 불가능한 발행 억제(후반 현금 과잉/발행 부채 감소). 전 맵 공통 +VP, 특히 St. Lucia 파산률 개선.
3. **미완성 트랙 억제** — 한 턴 슬롯으로 완성 불가능한 경로 착공 차단을 강화(이미 일부 존재, blockedEdges 회피와 함께 효과 상승).
