# AI 다인 맵 성능 베이스라인 (100시드)

다인(3인+) 맵 AI의 성능 기준 데이터. **AI 로직을 바꿀 때마다 이 표와 비교**해 회귀/개선을 판정한다.
모든 수치는 **100시드** 동기식 전체게임 시뮬레이션 평균(셋업만 시드 고정, AI 결정은 실난수 — 8/20시드는
편차가 커 노이즈가 크므로 반드시 100시드 이상으로 측정).

## 측정 방법

```bash
npx vitest run src/ai/__tests__/rustBeltSimulation.test.ts \
  src/ai/__tests__/koreaSimulation.test.ts \
  src/ai/__tests__/germanySimulation.test.ts \
  src/ai/__tests__/westernUsSimulation.test.ts -t "베이스라인" 2>&1 | \
  grep -aE "=====|평균 accurate|파산: |1번\(선공\)|최종 승자|경매 입찰|1번 획득|turnOrder 행동|player[1-6]: VP"
```

출력 지표: 평균 accurateVP(완성 링크 트랙만 +1), 파산/게임, 1번(선공) 점유 분포, **최종 승자 분포**,
**player별 평균**(건설/수송/엔진/주식/income/VP/완성트랙). player별 지표는 player-index 편향 진단용.

- 2인 맵(tutorial·St.Lucia)은 순서 고착 개념이 약해 이 표에서 제외. tutorial VP 회귀는 고정시드
  `fullGameSimulation.test.ts`가 별도 게이트(평균 ≥ 9.3, 파산 0). ⚠️ St.Lucia(2인)는 현재 기존부터
  AI 파탄 상태(VP ≈ −23, 파산 18/20) — 별도 미해결 이슈.

## 진단 지표 (상시 출력, player-index 편향·순서 고착 추적용)

각 다인 시뮬 로그에 아래 진단 지표가 **항상** 출력된다(2026-06-25 추가). "누가 1번을 먹나·왜 정체하나"를
수치로 추적해 인위적 보정 없이 진짜 원인을 규명하는 도구다.

- **경매 입찰 발생**: N회/게임. 0에 가까우면 경매가 양보로만 결정 = 순서 안 섞임.
- **1번 획득 — 입찰로(byBid) / 양보로(byYield)**: 1번을 돈 주고 따냈나(byBid) vs 아무도 안 사서 됐나(byYield).
- **turnOrder 행동 선택 횟수**: player별 turnOrder 선택 — 순서 탈환 시도 빈도.
- **순번 1~N위 점유 분포**(Western): player별 각 순번 횟수. "앞 절반 고착" 직접 진단.
- **(Western) 1게임 턴별 프로세스 추적**(`-t "프로세스 추적"`): player별 매 턴 경로/건설좌표 + skip 시
  게이트 이유(완성/from·to연결/completable/필요트랙). 정체·붕괴 원인 추적의 핵심.

## 이번 작업 요약 (Western 골고루 — 마을 큐브가 핵심 해결)

- **Western US "1·2·3등 고착" 해소**: 승자 분포 29/37/15/12/**2/5** → 25/16/19/14/**11/15**(뒤3 player가
  거의 못 이기던 것 → 11~15%로 균등). player별 VP 격차 30(32→2)→약 10(19.8→9.0). 파산 0.79→0.37.
- **진짜 원인은 "마을 큐브 무시"였다**(1게임 추적으로 규명): Western은 townCubes 맵인데 경로 선택
  (`analyzeDeliveryOpportunities`)이 도시 큐브만 봐서, 도시 화물 소진 후 뒤 순번이 갇혀 정체→파산.
  마을 큐브 배달 목표 추가로 해결 — 갇힌 player가 중간 마을 큐브 배달로 income을 벌어 **전체 파이↑**.
  경매 순번·거점·turnOrder 조율(모두 시도)은 부차적이었다.
- **Rust Belt 동반 개선**: 첫착공 완성게이트로 9.80→11.80, 파산 1.12→0.92.
- **경매 보너스는 Western 전용**(교훈): cityCubes 맵(Rust/Germany)에 적용하면 뒤 순번이 1번 사느라
  건설예산 소진→붕괴(전 맵 적용 시 Rust VP 11.8→3.5·파산 2배). 마을 큐브가 부작용을 상쇄하는 Western만 안전.
- **순서 액션/경매 보너스 = 제로섬**: First Move/Build 강화·경매 순번 보너스는 1명만 선택+실질행동
  기회비용이라 player간 재분배에 그치고(붕괴가 순번만 옮겨다님), 평균 VP를 깎는다. 마을 큐브만 전체↑.
